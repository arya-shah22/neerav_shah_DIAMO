# DIAMO ERP – PHASE 11.9
## ENTERPRISE REPORT INTELLIGENCE, SCHEDULING & AUTOMATION SPECIFICATION

---

## 1. Executive Summary
This document defines the Enterprise Functional Specification Document (FSD) for the Report Intelligence, Automation, and Distribution module of DIAMO ERP. This module centralizes report indexes, user favorites, automated schedules, output version histories, and distribution rules to manage financial and operational information.

---

## 2. Report Library
Aggregates all ERP reports in a structured hierarchy:
*   *Categories:* Accounting, Financial, Sales, Purchase, Stock, GST, TDS/TCS, Outstanding, Cash/Bank, and Outsource Job Books.
*   *Custom Reports:* Supports saving custom report structures generated by users under an "Authorized Views" directory.

---

## 3. Favorite Reports
*   **User Configurations:** Allows pinning specific reports, arranging folder layouts, grouping related sheets (e.g., "Daily Cash Audit Group"), and setting a favorite report as the default startup screen.

---

## 4. Recent Reports
*   **Activity Logs:** Keeps tracking lists of recently opened, printed, exported, or scheduled reports, as well as most-frequently accessed reports for quick access.

---

## 5. Saved Report Views
*   **Layout Persistence:** Users can save specific layout selections, active column lists, filters, sort orders, and grouping keys.
*   **Access Scopes:** Can be saved as personal, department, or company-wide templates.

---

## 6. Report Automation
*   **Time Triggers:** Daily, weekly, monthly, quarterly, or yearly automated generation schedules.
*   **Condition Triggers:** Triggers reports when specific operational conditions are met (e.g., when cash reserves drop below ₹500,000, send an immediate Treasury balance sheet).

---

## 7. Report Distribution
*   **Distribution Channels:** Emails PDF/Excel files to selected groups or copies reports to shared network paths.
*   *Integration:* Renders formats compatible with WhatsApp notifications or Slack channels (future compatibility).

---

## 8. Email Settings
*   **SMTP Configuration:** Supports single/multiple recipients, CC/BCC controls, custom subject/message templates, and secure attachments.

---

## 9. Report Archive
*   **Retention Policies:** Saves generated historical reports in a secure server file storage directory.
*   **Document Versioning:** Assigns version numbers to repeat outputs to track revisions.

---

## 10. Report Versioning
*   *Columns:* Version ID, Document Name, Date Generated, Triggered By, Query Parameters Used (JSON description of active filters), Format (PDF/Excel), and Reference ID.

---

## 11. Smart Search
*   **Query Parser:** Resolves natural language searches into database query variables (e.g., searching "Supplier outstanding over ₹50k" matches the Accounts Payable report with an amount filter).

---

## 12. Global Filters
Filters reports by: Company, Financial Year, Active Branch Vault, User ID, and Saved View ID.

---

## 13. Report Dashboard
*   **KPI Summary Card:** Active schedules, failed schedules, pending emails, today's generated reports, and top-used reports.

---

## 14. Security
*   **Role-Based Access Control:** Limits report generation, printing, exporting, or template saving to authorized user roles.
*   **Period Locks:** Prevents editing layouts or parameters in closed financial periods.

---

## 15. Audit
Logs all status changes:
*   Tracks report access, exported file histories, search inputs, and parameter changes.
*   Logs before and after JSON snapshots, user IDs, and system timestamps.

---

## 16. Notifications
*   **Status Alerts:** Confirms successful prints, completed exports, or automated email dispatches.
*   **Filing Reminders:** Alerts tax managers before filing deadlines.

---

## 17. Performance
*   **Asynchronous Processing:** Long-period general ledger reports run in a background worker thread.
*   **Data Virtualization:** The UI uses lazy loading to render reports with 1,000,000+ rows without performance lag.

---

## 18. Validation
*   **Filing Validation:** Ensures correct email formats, active printer connections, and valid date bounds before starting generation tasks.

---

## 19. Business Rules
1.  **Strict Balance Constraint:** Voucher save blocked if variance is not zero.
2.  **No Edits on Reconciled Vouchers:** Reversing or editing a voucher requires first undoing its reconciliation.
3.  **Approval Logs:** Historical approval records cannot be deleted.

---

## 20. Edge Cases
*   **Mid-Year Edits:** Edits to historical transaction dates trigger automatic recalculations of all subsequent running balances.
*   **Closed Period Postings:** Blocks transaction entries in closed financial periods.

---

## 21. Future Enhancements
*   **AI Financial Summaries:** Summarizes ledger trends in plain language.
*   **Natural Language Querying:** Translates user questions into query filters automatically.

---

## 22. Architect Recommendations
1.  **Unique Barcode Constraints:** Enforce unique packet numbers to prevent overlapping dispatches.
2.  **Stateless Tracking API:** Run ageing calculations in background worker processes to prevent UI lag.
